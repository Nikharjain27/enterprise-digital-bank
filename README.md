# Enterprise Digital Banking Platform

Production-grade cloud-native banking platform built using:

- Java 21
- Spring Boot
- Microservices
- React
- PostgreSQL
- Kafka
- Redis
- Docker
- Kubernetes

- Microservices Architecture

- Cloud-Native Design
- Distributed Systems
